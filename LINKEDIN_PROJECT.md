# Web ERP

Web ERP is a portfolio recreation of my 2023 academic ERP project. I rebuilt the application in 2026 with ASP.NET Core MVC, C#, Entity Framework Core, and Microsoft SQL Server. The pages use HTML, CSS, and JavaScript.

The application includes a dashboard, customers, invoices, vendors, and purchase orders. Invoices and purchase orders have line items, totals, and status. The database is created on startup and filled with fictional sample data. This repository is a new implementation. It is not the original 2023 source code.

GitHub: https://github.com/janibasha1024-coder/web-based-erp

## Skills

- C#
- ASP.NET Core MVC
- Entity Framework Core
- Microsoft SQL Server
- HTML, CSS, and JavaScript
